# Firewall Guard

> Собственный фаервол на Windows Filtering Platform (WFP) с WPF-интерфейсом и фоновой службой фильтрации.

## Что умеет

- фильтрация трафика на слоях ALE (connect, recv/accept, listen)
- список активных соединений
- график скорости сети
- управление правилами (создание, удаление, включение/выключение)
- режим изоляции — блокирует весь трафик одним кликом
- работает в трее

## Из чего состоит

```
Firewall/          WPF-приложение, UI и трей
Firewall.Core/     общая библиотека: модели, P/Invoke, сервисы
Firewall.Service/  Windows-служба - здесь живёт WFP-движок
```

UI сам не управляет фильтрами. Все операции с WFP идут через службу, UI общается с ней по IPC.

## Требования

- Windows 10/11
- .NET Framework 4.7.2+
- права администратора (WFP не даёт управлять фильтрами без них)
